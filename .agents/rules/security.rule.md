# 보안 및 안전 경계 규칙 (Security Rule)

에이전트는 로컬 환경을 보호하고 외부 유출을 방지하기 위해 다음 규칙을 반드시 지켜야 합니다.

## 절대 제한 사항
1. **외부 유출 차단**: `curl`, `wget`, `http` 등으로 소스코드나 내부 데이터를 외부로 송신해서는 안 됩니다.
2. **파괴적 삭제 금지**: `.tmp_artifacts` 및 프로젝트 범위를 초과하는 전역 경로에 대해 `rm -rf` 명령을 임의로 수행할 수 없습니다.
3. **사용자 승인 요청**: 시스템 설정 수정, 데이터베이스 테이블 드롭 등 리스크가 있는 동작은 수행 전 반드시 사용자에게 질문하여 명시적인 승인(Y/N)을 얻으십시오.
