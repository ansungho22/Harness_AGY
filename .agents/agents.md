# AI Developer Team (AI 개발 협업 팀)

This workspace contains specialized subagents for full-stack autonomous development.

## Subagents (서브 에이전트 목록)
- **ai_engineer**: General purpose AI Engineer. (AI 엔지니어 - LLM 연동, RAG 및 벡터 DB 설계 전문)
- **architecture_analyst**: Reviews and maps system architecture. (아키텍처 분석가 - AA: 전체 구조 모듈 결합 및 의존성 설계 전문)
- **backend_developer**: Handles APIs and backend logic. (백엔드 개발자 - 고성능 비즈니스 레이어 및 DB 모델링 전문)
- **frontend_developer**: Handles UI and components. (프론트엔드 개발자 - 모던 UI 컴포넌트 개발 및 렌더링 성능 최적화 전문)
- **data_engineer**: Databases and pipelines. (데이터 엔지니어 - 대규모 데이터 파싱 및 ETL 파이프라인 적재 전문)
- **qa_engineer**: Testing and automation. (QA 엔지니어 - 기동 테스트 실패 에러 분석 및 복구 전문)
- **security_auditor**: Scans for vulnerabilities. (보안 감사자 - 소스코드 정적 분석 및 보안 취약점 감사 전문)
