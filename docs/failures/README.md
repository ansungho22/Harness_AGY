# Failures & Lessons Learned - 실패 및 교훈 기록

본 디렉토리는 과거에 시도했으나 설계 결함, 성능 이슈, 운영 비용 등의 이유로 실패하고 폐기된 설계나 기술적 접근법을 기록하는 곳입니다.

에이전트는 여기에 기록된 아키텍처나 패키지 도입 실패 원인을 반드시 학습하여, **동일한 실수를 반복하지 않도록 제한**받습니다.

## 기록 서식 예시 (Template)
* **실패한 아키텍처/라이브러리**: (예: Celery 비동기 큐 도입)
* **시도한 시점**: (예: 2025년 3월)
* **실패 및 문제 증상**: (예: 메모리 누수 현상 및 소규모 인프라 대비 높은 오버헤드 발생)
* **도출된 대안 및 교훈**: (예: 경량 비동기 처리가 필요할 때는 라이브러리 대신 언어 자체의 비동기 코루틴(asyncio)을 사용할 것)
