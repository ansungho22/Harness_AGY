# Architecture Decision Records (ADR) - 아키텍처 결정 기록

본 디렉토리는 프로젝트 내에서 이루어진 중요한 아키텍처 및 기술적 결정들을 기록하는 저장소입니다. 

에이전트는 새로운 아키텍처 요소를 제안하거나 코드를 작성하기 전, 반드시 여기에 기록된 과거의 의사결정 내역을 조회하고 이를 존중하여 설계해야 합니다.

## ADR 파일 목록 서식 예시 (Template)
새로운 아키텍처 결정을 추가할 때는 `XXXX-title.md` 형식(예: `0001-use-orm-instead-of-raw-query.md`)으로 기록합니다.

### 표준 구성 요소
1. **제목 (Title)**: `ADR XXXX: [결정 요약]`
2. **컨텍스트 (Context)**: 이 결정을 내리게 된 배경과 해결해야 했던 문제 상황.
3. **결정 (Decision)**: 선택한 대안 및 구현 방법.
4. **결과 (Consequences)**: 이 결정으로 인해 얻는 이점과 감수해야 하는 제약 사항.
